TABELAS VERDADE

O QUE É A ATABELA VERDADE E ONDE ELA SE ENCAIXA NO MUNDO DA PROGRAMAÇÃO? 

                Uma média-verdadeé uma ferramenta matemática que lista todas as modificações possíveis de valores lógicos (verdadeiro ou falso) para prever o resultado de uma expressão composta. 
                
                O que é a Tabela-Verdade?A tabela-verdade mostra todas as situações possíveis entre variáveis ​​lógicas. 
                Ela usa operadores lógicos fundamentais para definir um resultado final: 
                E (AND): Retorna verdadeira apenas se todas as entradas forem verdadeiras.
                OU (OR): Retorna verdadeira se pelo menos uma das entradas para verdadeira.
                NÃO (NOT): Inverta o valor lógico atual (o que é verdadeiro vira falso).Na programação, a tabela verdade é usada para avaliar expressões condicionais e controlar o fluxo do programa. 
                Função na Lógica de ProgramaçãoNa programação, a tabela-verdade serve para orientar decisões dentro do código. 
                Estruturas condicionais ( if, else, while): Ajuda a criar regras complexas combinando várias condições (por exemplo: if (usuarioLogado AND temPermissao)).
                Depuração de código: Facilita a localização de erros em regras de negócios confusas ou cheias de negações.
                Otimização de código: Permite simplificar expressões lógicas grandes sem alterar o comportamento do sistema.
